## Generated sprites

Sprites listed below were generated for this project (original art, no franchise assets).

Generator: procedural Python/PIL drawing script `assets/src/make_sprites.py` (vector shapes + cel shading + outline), written
for this project. The planned Higgsfield gpt_image_2_6 generation was unavailable (account plan),
so no AI image model was used. All sprites are original; glyphs are invented marks, not a real script.
License: same as this project.
